-------------------- 1. DUA MODE JALAN --------------------

  npm start       -> server.cjs sebagai proses UTAMA. Membuka port HTTP
                     (default 127.0.0.1:8090). UI dilayani via HTTP biasa.
  npm run app     -> Electron. UI lewat protokol app://, BACKEND JALAN
                     IN-PROCESS lewat core.js. TIDAK ADA port terbuka.
  npm run app:wsl -> sama, tapi backend dijalankan DI DALAM WSL
                     (env WOLFSPACE_BACKEND=<url>; UI memuat dari sana,
                     preload mematikan bendera ipc, frontend memakai HTTP).
  npm test        -> Jest (~18 suite). npm run dist -> installer Windows.
  npm run typecheck -> tsc untuk agent/ dan public/.

KUNCI YANG SERING MENYESATKAN: server.cjs hanya memanggil server.listen()
bila ia modul utama (`if (require.main === module)`, server.cjs:5432).
core.js me-require server.cjs SEBAGAI MODUL - mendapat "permukaan logika"
TANPA membuka port. Jadi `curl 127.0.0.1:8090` kosong padahal aplikasi
(mode Electron) berjalan normal.

  UI (app.jsx)

    |                                                     | core().selfAgentStream
    v                                                     v

    | state di-checkpoint ke MemorySaver (globalThis.__wolfspaceAgentMemory)
    | task_checklist disuntik ulang TIAP langkah

                        | gerbang kualitas (code-quality.cjs) + safe-edit

  thread baru dan agent mulai dari NOL. UI menyimpannya di localStorage
  (kedaluwarsa 30 menit, dihapus saat run tuntas) supaya reload tak membuat
  agent lupa lalu mengulang kerja.

-------------------- 15. CELAH YANG DIKETAHUI --------------------

  1. engines berbohong: package.json ">=18", batas nyata Node >= 20 (zona).
  2. bash tak terkurung di Windows (jail hanya Linux; regex bocor).
  3. Zona tanpa batas sumber daya sendiri (hanya .wslconfig per-VM).
  4. conhost.exe bocor satu per sesi terminal (anak server, tak terjangkau
     taskkill /T).
  5. Penangan uncaughtException di server.cjs menelan pesan asli (MODULE_
     NOT_FOUND terlihat sebagai exit 7).
  6. Riwayat chat dirender utuh tanpa batas node DOM (hanya editor yang
     dibatasi ke yang terlihat).
  7. Model lokal tak terhubung (skrip llama.cpp ada, tak ada pemanggil
     askModelStream; kunci cloud wajib).
  8. trace.cjs praktis stub -> /debug/runs selalu kosong.
