🐺 WOLFSPACE

A local, open-source AI coding workspace that proves its code by actually running it.

model guesses → your CPU runs it → pass / fail (real)

Most AI coding tools hand you code and hope it works. WOLFSPACE treats the model as an untrusted guesser and your CPU as the judge: generated code is executed, and the agent cannot declare itself done without a successful run to point at.

This page is not the app. WOLFSPACE runs code, spawns processes, and keeps a persistent workspace — none of which exist on static or serverless hosting. Install it locally or run the container.

Get it

Download installer Source on GitHub

The Windows installer is not code-signed yet, so SmartScreen warns on first run — choose More info → Run anyway.

Run from source

git clone https://github.com/tegardave-alt/Wolfspace-ai-native
cd Wolfspace-ai-native
npm install
npm start          # → http://127.0.0.1:8090

Run in a container

docker build -t wolfspace .
docker run -p 8090:8090 -v wolfspace-data:/data wolfspace

Runs as a non-root user, honours an injected PORT, and exposes /healthz — deployable to Railway, Render, Fly.io, or any VPS.
